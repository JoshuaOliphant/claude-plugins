# Action Verbs by Career Level and Domain

## Entry-Level (0-3 years)

### Technical
- Assisted, Built, Coded, Created, Debugged, Designed, Developed
- Documented, Implemented, Integrated, Maintained, Programmed
- Resolved, Supported, Tested, Troubleshot, Updated, Wrote

### Analytical
- Analyzed, Assessed, Calculated, Collected, Compiled, Evaluated
- Examined, Identified, Investigated, Mapped, Measured, Researched
- Reviewed, Studied, Surveyed, Tracked, Validated, Verified

### Communication
- Communicated, Contributed, Coordinated, Demonstrated, Drafted
- Explained, Facilitated, Organized, Participated, Prepared
- Presented, Reported, Summarized, Trained, Translated

## Mid-Level (3-8 years)

### Technical Leadership
- Architected, Automated, Configured, Delivered, Deployed
- Engineered, Enhanced, Established, Executed, Improved
- Migrated, Modernized, Optimized, Overhauled, Rebuilt
- Redesigned, Refactored, Scaled, Standardized, Streamlined

### Project Management
- Achieved, Administered, Advanced, Championed, Consolidated
- Defined, Directed, Drove, Elevated, Eliminated, Exceeded
- Expanded, Formulated, Generated, Initiated, Launched
- Led, Managed, Mentored, Owned, Planned, Produced
- Proposed, Reduced, Resolved, Revamped, Shaped, Steered

### Analytical
- Benchmarked, Diagnosed, Discovered, Forecasted, Interpreted
- Modeled, Predicted, Prioritized, Quantified, Recommended
- Strategized, Systematized, Validated

## Usage Guidelines

1. **Never repeat the same verb** for consecutive bullets
2. **Match verb strength to career level** — don't use "Spearheaded" for an internship
3. **Past tense for previous roles**, present tense for current role
4. **Avoid weak verbs**: Helped, Tried, Attempted, Was responsible for, Participated in
5. **Pair verbs with metrics**: "Optimized" alone is weak; "Optimized query performance by 60%" is strong
